多基站部署拓扑

三个边界：矿区边缘、控制面、数据面。每个节点都标注实际运行的服务和版本，路径标注协议与端口。

READING NOTE

本地演示与多站演进

  • 单站默认仍然是本地桌面 + 本地 HTTP 服务 + 本地 MySQL。
  • 多站模式把边缘节点、中心站和 MEC 分流作为独立部署面展示。
  • 控制面是单点关键组件，数据面保存指标、时序和结果文件。
