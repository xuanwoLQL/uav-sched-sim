State machine · 七态与终止态

任务生命周期状态机

状态名称与 task_record.state 对齐。弱网、退避、缓存和看门狗不是旁注，而是任务能否完成的主路径。

READING NOTE

为什么要画阻塞与缓存

  • 弱网不是简单的失败，而是会触发重试、退避、缓存和重新入队。
  • 取消是跨状态事件，用旁注表达，避免从每个状态重复画一条线。
  • 完成、失败、取消是三个不同的终止语义。
