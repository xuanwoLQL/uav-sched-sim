# 界面重构预览

本轮重构把原来的“3D 场景 + 浮动面板”整理为工程监控工作台，功能与数据口径保持不变。

## 预览文件

| 文件 | 内容 |
|---|---|
| `01-main-dashboard-1480.png` | 1480×920 主监控台：左侧机群/队列，中间 3D 现场，右侧运行遥测与共识 |
| `02-results-charts.png` | 结果工作区：数据快照、关键结论、分组的图表资产 |
| `03-results-matrix.png` | 15 组实验矩阵，动态权重行有固定高亮 |
| `04-results-replay.png` | 时序回放与逐时刻读数 |
| `05-results-compare.png` | 基线/对照双策略差异与叠加曲线 |
| `06-results-ci.png` | 重复实验均值 ± 95% 置信半宽 |
| `07-os-inspector.png` | OS 微观透视镜在新工作台中的呈现 |
| `08-exe-packaged.png` | 重新打包后的单文件 exe 实际加载新版页面 |

## 设计原则

- 固定阅读顺序：任务控制 → 3D 现场 → 实时遥测；重要状态首屏可见。
- 统一材质与状态色：冷灰边界、青绿表示在线/正常、琥珀表示关注、红色表示风险。
- 数字优先：使用等宽数字、紧凑单位和同屏对照，减少解释性长句。
- 结果页分层：数据快照 → 关键结论 → 图表/矩阵/回放明细。
- 保留所有原功能：开始/停止、结果页签、OS 透视、天气切换、渲染模块、重跑与导出。
